This is the day00 of the Piscine Python

The subject require to use the python version 3.10 

If you want to test it on 42's computers you can launch a virtual environnement. There are 2 ways of doing; 

```
	uv venv --python 3.10 .venv
```

or

```
    python3 -m venv .venv
```

Once done you need to activate the virtual environment ; 
```
source .venv/bin/activate
```

If you need to stop the venv; 

```
deactivate
```
